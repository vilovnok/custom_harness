# Скил: web-research

Когда пользователь просит «разберись», «собери информацию», «сравни» — следуй шагам.

## Процесс

1. Сформулируй 3–5 конкретных под-вопросов.
2. Для каждого под-вопроса собери данные (файлы в рабочей директории, MCP-инструменты,
   поисковые инструменты, если подключены).
3. Фиксируй факт → источник. Ничего не выдумывай: если данных нет, так и напиши.
4. Если объём большой — делегируй сбор субагенту `researcher` через `task()`,
   а сам только сведи результат.

## Формат ответа

```
## Вывод
<2–3 предложения>

## Детали
- <факт> — <источник>
- ...

## Чего не хватает
- <открытые вопросы>
```
